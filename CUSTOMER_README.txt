OMNI REPORTS 1.0.0
Уведомления о заявках Авито из отчётов ОКК в Telegram

ЗАПУСК

1. Распакуйте архив в отдельную папку.
2. Откройте OmniReports.exe. Дополнительная установка не требуется.
   Первый запуск может занять некоторое время.
3. Введите токен Telegram-бота, логин и пароль Omni CRM.
   Кнопка «i» рядом с каждым полем открывает инструкцию.
4. Нажмите «Подключить и запустить».
5. В открывшемся чате Telegram нажмите «Запустить».
   Программа привяжет чат и начнёт проверку CRM.

СОЗДАНИЕ TELEGRAM-БОТА

1. Откройте официального @BotFather: https://t.me/BotFather
   Кнопка перехода также есть в подсказке к полю токена.
2. Отправьте /newbot.
3. Введите название бота.
4. Выберите уникальное имя латиницей с окончанием bot.
5. Скопируйте полученный токен вида 123456789:ABC... в программу.

Используйте отдельного бота, не подключённого к другой программе.
Токен предоставляет доступ к боту. Не передавайте его другим людям.

ФИЛЬТРЫ И ВХОД ЧЕРЕЗ БРАУЗЕР

Для настройки отдела, менеджера или статусов, а также при капче:

1. Нажмите «Приостановить» и дождитесь завершения текущей операции.
2. Выберите «Войти через браузер».
3. Войдите в CRM и откройте «Отчёты ОКК».
4. Установите нужные фильтры и нажмите «Поиск».
5. Не закрывая браузер, вернитесь в программу и нажмите
   «Сохранить отчёты».
6. После сохранения нажмите кнопку запуска.

Если автоматический вход не удался, используйте вход через браузер.
Аккаунту CRM должен быть доступен раздел «Отчёты ОКК».
При первом подключении сравните найденные заявки с CRM,
включая все страницы и выбранные фильтры.

ПРОВЕРКА ЗАЯВОК

Период: вчера и сегодня по времени Windows, обновляется автоматически.
Отбор: подстрока «авито» в колонке «Реклама», без учёта регистра.
Интервал: 60 секунд после завершения предыдущей проверки.

При первом запуске отправляются все найденные заявки за этот период.
Затем отправляются только номера, которых ещё нет в истории отправок.
Изменение ранее отправленной заявки не вызывает повторное уведомление.
История сохраняется после перезапуска программы и компьютера.

Оставляйте программу открытой, а компьютер включённым и без сна.
Закрытие окна останавливает проверки. Завершение текущего запроса
может занять около минуты. Без интернета уведомления не отправляются.
Заявки за пределами периода «вчера — сегодня» не проверяются.
При сбое сразу после доставки сообщения возможна повторная отправка.

ПОВТОРНЫЙ ЗАПУСК И ОБНОВЛЕНИЕ

Откройте OmniReports.exe и нажмите «Запустить мониторинг».
Логин и пароль не требуется вводить, пока действует сессия CRM.
Если срок сессии истёк, войдите повторно.

Для обновления закройте программу и замените только EXE.
Настройки и история останутся на компьютере.

Настройки, сессия и история хранятся в:
%LOCALAPPDATA%\OmniReports

Папку можно открыть кнопкой «Открыть папку данных».
Не удаляйте и не передавайте её: она содержит токен и сессию CRM.
Пароль CRM в настройки не записывается.
На другом компьютере выполните подключение заново.

СИСТЕМНЫЕ ТРЕБОВАНИЯ

Windows x64. Проверено на Windows 10, сборка 19045.
Windows 11 соответствует требованиям встроенного браузерного движка;
отдельная проверка на Windows 11 не проводилась.
Windows 7/8, Windows 32-бит, macOS и Linux не поддерживаются этой сборкой.
Нужны интернет и свободное место для распаковки встроенного браузера.
Python и отдельный браузер устанавливать не требуется.

EXE не имеет цифровой подписи. Windows может показать предупреждение
о неизвестном издателе.

В папке licenses находятся лицензии используемых компонентов.
