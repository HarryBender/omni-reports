# Omni Reports

Приложение для Windows, которое проверяет отчёты ОКК в Omni CRM и отправляет заявки Авито в Telegram.

В окне подключения три поля: токен Telegram-бота, логин и пароль CRM. Рядом с полями расположены кнопки с инструкциями. Для настройки отделов, менеджеров и статусов предусмотрен вход через браузер.

## Как работает

- При каждой проверке устанавливает период «вчера — сегодня» по времени Windows.
- Ищет подстроку «авито» в колонке «Реклама», без учёта регистра.
- При первом запуске отправляет все найденные заявки за этот период.
- Затем отправляет только номера, которых ещё нет в истории отправок.
- Сохраняет историю после перезапуска программы и компьютера.
- Делает паузу 60 секунд после завершения предыдущей проверки.

Для работы приложение должно оставаться открытым, а компьютер — включённым и подключённым к интернету. Во время сна и после закрытия окна проверки не выполняются.

## Требования

Готовая сборка рассчитана на Windows x64. Запуск EXE и встроенного браузера проверен на Windows 10, сборка 19045. Windows 11 соответствует требованиям используемого браузерного движка; отдельная проверка на Windows 11 не проводилась. Windows 7/8, Windows 32-бит, macOS и Linux этой сборкой не поддерживаются.

Для работы с исходниками нужны Windows x64 и Python 3.11 или новее. Релиз 1.0.0 собран на Python 3.14.7. Версии основных зависимостей зафиксированы в файлах требований.

## Подготовка окружения

В PowerShell, в папке проекта:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-build.txt
.\.venv\Scripts\python.exe -m playwright install chromium
```

Активация окружения не требуется. Chromium устанавливается в стандартную папку Playwright текущего пользователя Windows.

## Запуск из исходников

```powershell
.\.venv\Scripts\python.exe desktop.py
```

1. Создайте отдельного бота через официальный [@BotFather](https://t.me/BotFather), командой `/newbot`.
2. Введите полученный токен, логин и пароль Omni CRM.
3. Нажмите «Подключить и запустить».
4. В открывшемся чате с ботом нажмите «Запустить». Программа определит ваш чат автоматически.

Если нужны фильтры CRM или на странице входа есть дополнительная проверка, используйте «Войти через браузер». Откройте отчёты ОКК, установите фильтры, нажмите «Поиск», затем «Сохранить отчёты» в приложении.

Подробная инструкция для пользователя находится в [CUSTOMER_README.txt](CUSTOMER_README.txt).

## Сборка EXE

```powershell
.\.venv\Scripts\python.exe build_desktop.py
```

Результат: `dist/release-build/OmniReports.exe`.

В EXE включаются Python, зависимости, интерфейс и Chromium. Пользователю не нужно устанавливать их отдельно. Размер файла — около 381 МБ. При запуске встроенные файлы распаковываются во временную папку, поэтому требуется дополнительное свободное место.

Токены, браузерные сессии, базы и логи не включаются в сборку. EXE не имеет цифровой подписи.

## Архив для передачи пользователю

После сборки выполните:

```powershell
.\.venv\Scripts\python.exe package_release.py
```

Результат:

- `dist/OmniReports-1.0.0-windows-x64.zip` — EXE, инструкция и лицензии компонентов.
- `dist/OmniReports-1.0.0-windows-x64.zip.sha256` — контрольная сумма архива.

Скрипт проверяет состав и целостность ZIP. При подготовке лицензий используется локальная страница `chrome://credits/` встроенного Chromium.

Версия релиза указана в `version_info.txt`, `package_release.py`, `desktop_ui.html` и `CUSTOMER_README.txt`. При выпуске новой версии обновляйте её в этих файлах.

## Проверки

```powershell
.\.venv\Scripts\python.exe -m unittest -v test_monitor.py test_desktop.py
.\dist\release-build\OmniReports.exe --self-test
```

Тесты проверяют отбор заявок, историю отправок, обработку ошибок Telegram, интерфейс, подсказки и вход на тестовой форме CRM. Во время проверки открывается тестовое окно браузера. Реальные Telegram-аккаунты и учётные данные CRM не используются.

Команда `--self-test` проверяет упакованный интерфейс, встроенный браузер, поля дат и чтение тестовой таблицы. Результат записывается в `%LOCALAPPDATA%\OmniReports\self-test.json`.

Автоматический вход, права доступа, сохранение фильтров и полноту обхода страниц нужно проверить на используемом аккаунте CRM.

## Данные пользователя

Приложение хранит данные отдельно от исходников:

```text
%LOCALAPPDATA%\OmniReports
```

В этой папке находятся настройки с токеном Telegram, сессия браузера и история `sent.sqlite3`. Пароль CRM в настройки не записывается. Пока действует сессия, повторный ввод логина и пароля не требуется.

Не публикуйте и не передавайте папку данных. При обновлении достаточно заменить EXE. При переносе на другой компьютер выполните подключение заново.

В `.gitignore` исключены настройки, профили, базы, логи, окружение Python и сборки. Исходники подготовлены без личных данных.

## Ограничения

Заявки вне периода «вчера — сегодня» не проверяются. Изменение уже отправленной заявки не вызывает повторное сообщение. При сбое после фактической доставки сообщения и до сохранения истории возможен повтор.

Если CRM изменит форму входа, заголовки таблицы, поля дат или навигацию по страницам, код потребуется обновить. Срок действия сессии определяется CRM.
